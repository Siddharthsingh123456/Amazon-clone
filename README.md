# Amazon-Inspired Shopping UI Clone

A small frontend practice project that recreates selected elements of an online shopping homepage for learning HTML and CSS layout techniques.

## Project contents
- `index.html` — repository-level entry page
- `Amazon clone/index.html` — project page
- `Amazon clone/style.css` — project styling

## Technology
- HTML5
- CSS3

## Run locally
```bash
git clone https://github.com/Siddharthsingh123456/Amazon-clone.git
cd Amazon-clone
```

Open `index.html` in a browser. If you want to inspect the nested project version, open `Amazon clone/index.html`.

No package installation or build step is required for this static frontend.

## Learning objectives
- Build page structure with semantic HTML
- Practice layout, spacing, typography, and responsive styling
- Organize static assets and stylesheets
- Recreate common e-commerce interface patterns
